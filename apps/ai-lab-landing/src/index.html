LOCAL AI LEARNING SPACE

Learn with AI agents, on your own device.

AI Agents Lab is a local learning and discussion environment that can use Ollama, LM Studio, or vLLM on your own device. Conversations, models, and storage stay on the computer where you run it.

This public page is a guide only. The Lab, its models, and its conversation history are never hosted here.

GET STARTED

Run the Lab locally.

  1. Download and extract the ZIP. Extract it to a folder you control, such as Documents\\AI-Agents-Lab. There is no hidden installation folder: this extracted folder is the Lab.
  2. Install Python and choose a local engine. Install Python 3.9 or later for Windows, then use one of the official provider links above.
  3. Run a local model or server. With Ollama, for example, run ollama pull qwen3:4b; the Lab uses its local address, 127.0.0.1:11434. LM Studio and vLLM expose OpenAI-compatible local servers on their configured loopback addresses.
  4. Keep Ollama local-only if you use it. Add "disable_ollama_cloud": true to %USERPROFILE%\.ollama\server.json, preserving any existing settings, then restart Ollama. Use downloaded local models, not names ending in :cloud.
  5. Start the local server from the extracted ZIP folder. Open start-windows.bat in that extracted folder (or run py -3 server.py there) and keep its window open. Its first run creates a Desktop shortcut that continues to open this extracted copy.
  6. Only after the local server has started, open the local address. When the start-windows.bat window confirms that the Lab is running, select Open Local Lab. The link cannot start the Lab by itself.

Manual updates — important: You do not download the ZIP each time you start the Lab. Download a new AI-Agents-Lab-Windows.zip only when you choose to update to a newer version. Keep your existing local models and back up data/campus.sqlite3 before moving to the new extracted folder. Then run start-windows.bat there once to update the Desktop shortcut.

PRIVACY

This site does not run the Lab.

There is no sign-in, chat input, model endpoint, telemetry, or personal-data collection on this Pages site. The download is a versioned local package; to use the Lab, extract it and connect only to a local Ollama, LM Studio, or vLLM installation.
