# Production Readiness Gate

- [ ] Production configuration is validated.
- [ ] Deployment is reproducible.
- [ ] Environment separation is correct.
- [ ] Secrets and keys are managed securely.
- [ ] Database migrations are tested.
- [ ] Health checks exist.
- [ ] Monitoring and alerts are active.
- [ ] Security-relevant logs are available.
- [ ] Rollback is documented and tested where required.
- [ ] Backups are active.
- [ ] Restore has been tested.
- [ ] Incident ownership and procedures exist.
- [ ] Runbooks are current.
- [ ] Support and maintenance ownership are assigned.
- [ ] Known limitations are documented.
- [ ] Required legal, privacy, or operational approvals exist.

**Result:** PASS / FAIL / NOT APPLICABLE
