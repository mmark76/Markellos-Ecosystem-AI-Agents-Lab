GET STARTED

Start in three simple steps.

  1. Download the ZIP. Use the public BETA download above. You do not need a GitHub account.
  2. Extract the ZIP. Extract it into a folder such as Documents.
  3. Set up and start. Double-click Start AI Training Lab.bat. Easy Start checks your device and asks separately before installing Python, Ollama, or the initial local model. When ready, it starts the Lab at Open Local Lab.
