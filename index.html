PURPOSE

One shared system, applied according to project risk and purpose.

This template packages the common lifecycle, design contracts, governance, and delivery starting point for Markellos Ecosystem projects. Individual repositories adopt applicable Foundation requirements through explicit, reviewed changes rather than automatic migration.

The template is a downstream package of the canonical foundations, not a foundation itself.
