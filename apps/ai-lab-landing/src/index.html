SERVICE BOUNDARY

Local by design

The Lab connects to a locally installed Ollama instance. It has no hosted AI API, analytics, or cloud chat backend.

GET STARTED

Run the Lab locally.

  1. Download and extract the ZIP. Extract it to a folder you control, such as Documents.
  2. Install the required local tools. Install Python 3.9 or later for Windows and Ollama for Windows.
  3. Download one local Ollama model. For example, open PowerShell and run ollama pull qwen3:4b. Keep Ollama running; the Lab connects only to its local address, 127.0.0.1:11434.
  4. Keep Ollama local-only. Add "disable_ollama_cloud": true to %USERPROFILE%\.ollama\server.json, preserving any existing settings, then restart Ollama. Use downloaded local models, not names ending in :cloud.
  5. Start the application. In the extracted folder, run py -3 server.py (or open start-windows.bat).
  6. Open the local address. Visit http://127.0.0.1:8765/ in your browser.

About LM Studio: LM Studio for Windows is optional for experimenting with local models. It is not required and does not replace Ollama for this version of the Lab, which connects specifically to Ollama's local API. Internet access is needed to install tools and download models; the Lab itself uses only the local Ollama service.

PRIVACY

This site does not run the Lab.

There is no sign-in, chat input, model endpoint, telemetry, or personal-data collection on this Pages site. The download is a versioned local package; to use the Lab, extract it and connect only to your local Ollama installation.
