# Cloudflare Deployment Record Template

Use this document only when a project explicitly selects a Cloudflare deployment. This Integrated Project Template does not prescribe Cloudflare, a hostname, a Pages project, or production configuration.

Record the selected infrastructure profile, owner, approved scope, environments, routing and trust boundaries, Shield requirements, deployment/rollback process, verification evidence, and production authorization. Do not include tokens, tunnel credentials, host-specific sensitive details, or deployment evidence not safe for the project repository.
