Which technology should I use?

Ollama: local inference. PyTorch: numerical training. Transformers: compatible local pretrained models. PEFT / LoRA: efficient adapters. TRL: supervised fine-tuning. CUDA: supported NVIDIA GPU acceleration. Training changes model parameters; agent exercises and evaluation do not.
