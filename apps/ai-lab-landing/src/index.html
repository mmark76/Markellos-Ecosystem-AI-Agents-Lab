INSTALLATION STATUS

Install the public BETA release.

  1. Download the official ZIP. Use the public BETA download above; GitHub access is not required.
  2. Verify and extract the ZIP. Confirm the displayed SHA-256 checksum, then extract it to a folder you control, such as Documents\\AI-Agents-Lab. There is no hidden installation folder: this extracted folder is the Lab.
  3. Install Python and Ollama. Install Python 3.9 or later for Windows, then install Ollama from the official link above.
  4. Run a local Ollama model. For example, run ollama pull qwen3:4b; the Lab uses Ollama only at 127.0.0.1:11434.
  5. Keep Ollama local-only if you use it. Add "disable_ollama_cloud": true to %USERPROFILE%\.ollama\server.json, preserving any existing settings, then restart Ollama. Use downloaded local models, not names ending in :cloud.
  6. Start the local server from the extracted ZIP folder. Open start-windows.bat in that extracted folder (or run py -3 server.py there) and keep its window open. Its first run creates a Desktop shortcut that continues to open this extracted copy.
  7. Only after the local server has started, open the local address. When the start-windows.bat window confirms that the Lab is running, select Open Local Lab. The link cannot start the Lab by itself.
