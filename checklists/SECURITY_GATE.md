# Security Gate

This DNA gate records project verification of applicable requirements and controls owned by [Ecosystem Security — The Shield](https://github.com/mmark76/Ecosystem-Security-The-Shield). Its checklist items are adoption prompts, not a competing security standard or control catalogue.

- [ ] Threat model is current.
- [ ] Assets, sensitive data, actors, and entry points are identified.
- [ ] Authentication matches the risk profile.
- [ ] Server-side authorization is verified.
- [ ] Least privilege is applied.
- [ ] Input validation is verified at trust boundaries.
- [ ] Output and browser protections are applied.
- [ ] Sessions and tokens are handled securely.
- [ ] Secrets are absent from code, logs, and client bundles.
- [ ] Data protection and privacy requirements are verified.
- [ ] API abuse, rate limits, files, and webhooks are addressed where applicable.
- [ ] Dependency and secret scans pass.
- [ ] Infrastructure and production configuration are reviewed.
- [ ] Security logging and incident paths exist.
- [ ] Backup and restore controls are verified.
- [ ] Critical open vulnerabilities equal zero.
- [ ] Unaccepted critical security risks equal zero.
- [ ] Unapproved critical exceptions equal zero.

**Result:** PASS / FAIL / NOT APPLICABLE
