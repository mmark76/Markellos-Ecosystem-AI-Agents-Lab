LOCAL AI LEARNING SPACE

Learn with AI agents, on your own device.

AI Agents Lab is a local learning and discussion environment powered by Ollama. Conversations, models, and storage stay on the computer where you run it.

Download for Windows ↓

WHAT IT OFFERS

Two focused ways to explore an idea.

University room

A professor and student agents turn a topic into a practical lesson, exercise, alternative solution, and feedback.

Conference room

An architect, developer, and reviewer examine a technical request with scope, risks, implementation steps, and verification in mind.

Local by design

The Lab connects to a locally installed Ollama instance. It has no hosted AI API, analytics, or cloud chat backend.

GET STARTED

Run the Lab locally.

  1. Download and extract the ZIP. No GitHub account is required. Extract it to a folder you control, such as Documents.
  2. Install Python 3.9+ and Ollama. Download at least one local model in Ollama.
  3. Disable Ollama cloud features. Add "disable_ollama_cloud": true to %USERPROFILE%\.ollama\server.json, preserving any existing settings, then restart Ollama.
  4. Start the application. In the local application folder, run py -3 server.py (or open start-windows.bat).
  5. Open the local address. Visit http://127.0.0.1:8765/ in your browser.

Privacy note: this public page is only a guide. The AI Agents Lab itself is intentionally not hosted here.
