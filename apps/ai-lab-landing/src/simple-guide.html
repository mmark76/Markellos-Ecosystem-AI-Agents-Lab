SIMPLE GUIDE

Start using AI Agents Lab

This guide describes the verified state of AI Agents Lab v0.1.24. The Local Lab runs on your own Windows computer and its conversations stay on your device.

Public download unavailable: v0.1.24 is hosted in a private GitHub repository, so anonymous visitors cannot download its ZIP. Do not rely on a public GitHub Release link until an authorized public distribution path exists.

What you need

  • A Windows computer.
  • Python 3.9 or later.
  • Ollama, with at least one local model. LM Studio and vLLM are not supported by this release.

Get started in six steps

  1. Obtain AI-Agents-Lab-Windows.zip through an authorized distribution path; anonymous public distribution is currently unavailable.
  2. Extract the ZIP to a folder you control, such as Documents.
  3. Install Python if it is not already installed.
  4. Install and start Ollama, then download a local model.
  5. Open start-windows.bat from the extracted Lab folder and keep its window open.
  6. When it says the Lab is running, open the local Lab in your browser. The first start also creates a Desktop shortcut.

Current feature status

  • Available: Local Agent Training with Ollama: Trainer → Student → Evaluator → Improver.
  • Under Construction: Agent Collaboration / Conference Room is disabled in the released interface.
  • Not yet operational: Optional advanced model fine-tuning has a confirmed training-worker compatibility issue.
  • Not implemented: The Local App has no in-app manual update check.

Updating: There is no in-app update checker in v0.1.24. Keep your current Lab folder until an authorized newer ZIP is available and working.
