GET STARTED

Start in three simple steps.

  1. Download the ZIP. Use the public BETA download above.
  2. Extract the ZIP. Extract it into a folder such as Documents.
  3. Set up and start. Double-click Start AI Training Lab.bat. Easy Start checks your device and asks separately before installing Python, Ollama, or the initial local model. It creates a Desktop shortcut so you can start the Lab next time without finding the BAT file. When ready, it starts the Lab at Open Local Lab.
