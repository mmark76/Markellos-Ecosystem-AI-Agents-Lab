# Brand Assets

Store approved master brand assets in this directory.

## Required Master Files

- `markellos-monogram.svg`
- `markellos-wordmark.svg`
- optional app-specific lockups as SVG
- raster exports only when required by a platform

## Rules

- SVG is the master format.
- Do not trace, redraw, distort, rotate, outline, shadow, or recolor the monogram arbitrarily.
- Keep the monogram geometry identical across all apps.
- The monogram may use the ecosystem brand blue, the current app accent, white, or a high-contrast single-color treatment.
- Use the app name outside the monogram rather than changing the monogram itself.
- Preserve clear space of at least one internal stem width around the mark.
- Do not place the mark on visually noisy backgrounds without a protective surface.
- Small icons must be optically simplified from an approved source, not recreated independently.

The screenshots supplied for the ecosystem establish the intended visual direction. Add the original vector artwork here before production release so all platforms use one exact asset.
