Understanding Model Fine-Tuning

Fine-tuning means taking an AI model that has already learned many things and teaching it further with carefully selected examples. You are adapting an existing model, not creating one from nothing.

Feature status: Model Fine-Tuning is under construction and cannot be started in this release. This page explains the idea; it does not install or train anything.

A simple example

Imagine you have an AI model that can discuss many subjects. You want it to become more useful for explaining chess positions. You prepare suitable examples of positions, explanations, and desired responses. Fine-tuning uses those examples to adjust the model. Afterwards, it might give more useful chess explanations, but improvement is not guaranteed: you must test it.

The four choices in a fine-tuning setup

  1. Which AI model? (Model)

    Choose the already trained model you want to adapt. A compatible model must be available locally.

  2. Which examples? (Dataset)

    Choose the information and examples the model will learn from. A common file format is JSON Lines (.jsonl), containing one structured example per line. Good-quality examples matter more than simply adding many.

  3. How should it learn? (Training Method)

    Supervised Fine-Tuning (SFT) trains with examples of the responses you want. Low-Rank Adaptation (LoRA) is a resource-saving way to update a relatively small set of trainable parameters. These are not opposites: SFT can use LoRA.

  4. Which computer resources? (Compute Device)

    CPU (Central Processing Unit) uses your computer's main processor and is often slower. GPU (Graphics Processing Unit) can speed up training; CUDA refers to supported NVIDIA GPU acceleration. Auto means the software selects an available supported device.

Fine-Tuning versus the Learning Lab

Learning Lab (Agent Collaboration)

AI agents exchange answers and feedback during a session. The original model's learned parameters do not change.

Fine-Tuning (Model Adaptation)

Training adjusts parameters or adapters using a dataset. You can save the resulting adapted model for later use.

Other names you may encounter

Ollama (Local Inference Runtime) runs models to produce answers. PyTorch (Machine Learning Framework) performs numerical training. Transformers (Model Library) supports compatible pretrained models. PEFT (Parameter-Efficient Fine-Tuning) groups approaches such as LoRA, while TRL (Transformer Reinforcement Learning Library) provides tools that include supervised fine-tuning. These are technologies behind the process, not extra steps you must complete just to use the Learning Lab.

What should you expect?

Training can take time, memory, and disk space. The adapted model may improve on your chosen examples, stay the same, or become worse on some tasks. Evaluate it on separate examples before deciding whether fine-tuning helped.
