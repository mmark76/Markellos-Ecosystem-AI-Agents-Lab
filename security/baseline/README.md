# Shield Adoption Boundary

The Shield owns security requirements, controls, baselines, and reusable patterns. The reviewed, sanitized snapshot is under `../../foundations/shield/`; this directory remains the project-safe adoption entry point.

Projects record their selected Shield revision, applicable requirements, control mappings, exceptions, and sanitized evidence in `docs/security/` and the traceability matrix. Render a selected pattern only into protected project-owned locations, validate it, and never commit populated credentials or production configuration.
